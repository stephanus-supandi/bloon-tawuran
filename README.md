# 🤡 BLOON TAWURAN — DPR vs RAKYAT

**A goofy, mobile-friendly HTML5 Canvas arena game.**

Play as BLOON, survive the chaos, and bonk your way through a cartoon battle in **The Great Bloon Arena**.

## Play online

Once GitHub Pages is enabled, play here:

https://stephanus-supandi.github.io/bloon-tawuran/

## Controls

### Desktop
- **WASD** or **Arrow keys** — move
- **Space** or **mouse click** — BONK

### Mobile
- **Left side** — virtual movement control
- **Right side** — BONK

## Run locally

No installation and no external dependencies are required. Download or clone this repository, then open `index.html` in a modern browser.

## About

- Built with vanilla JavaScript and HTML5 Canvas.
- Responsive layout for desktop and mobile browsers.
- Cartoon characters and fictional comedic conflict.
- No external libraries, trackers, or network calls.

## GitHub Pages

To publish the game:
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **master** and folder **/(root)**.
4. Save, then wait for GitHub Pages to finish deploying.
